# Raw evaluation output

Every number in [`../docs/EVALUATION.md`](../docs/EVALUATION.md) is derived from these
files. They are committed so the analysis can be checked and re-run without spending
anything.

| path | what it is |
|---|---|
| `runs/*.json` | one file per configuration: aggregate scores **and every per-question score, answer and retrieved context** |
| `runs_smoke_n5/` | 5-question smoke runs. **Not part of any reported result** — retained for provenance |
| `summary.csv` | aggregate scores, machine-readable |
| `by_category.csv` | per-question-category breakdown |
| `RESULTS.md` | generated by `scripts/05_report.py` |

## Read before reusing these numbers

**Runs are grouped by gold-set size and are only comparable within a group.** `*__n70`
runs used 70 questions (27 hand-written + 43 generated); `*__n27` used the 27 hand-written
questions only. Different questions, different difficulty — ranking across groups is
meaningless.

**`fixed_512__hybrid__n70.json` is invalid** and carries an `INVALID` key explaining why.
It predates the fix to `EnsembleRetriever`, which was returning the union of both
retrievers instead of top-k, so hybrid received 66% more context than dense. It is
excluded from every reported result.

**`answer_relevancy` is absent or NaN throughout.** It returns NaN on 100% of samples with
a Claude judge — see [`../docs/METRIC_SUPPORT.md`](../docs/METRIC_SUPPORT.md).
